# Vejrsystem for  Dalhul Len

## 

## Klima og årstider

Dalhul Len ligger i højlandet af Thornmark – et fugtigt, blæsende område præget af dale, floder og bjergkæder. Vejret er omskifteligt og brutalt ærligt: regn, tåge og kulde er lige så almindelige som sol.

| Årstid | Kendetegn |
| ----- | ----- |
| Forår (marts–maj) | Hyppig regn, kølige nætter, blomstring og mudrede stier. |
| Sommer (juni–august) | Lune dage, men tordenstorme og pludselige byger. |
| Efterår (sept.–nov.) | Tåge, kraftig vind og daggry med rimfrost. |
| Vinter (dec.–feb.) | Frost, sne, mørke og iskolde nætter. |

## Dagligt vejrslag

Rul **2d6** én gang pr. dag eller pr. rejseetape.

| Slag | Vejrtype | Effekt |
| ----- | ----- | ----- |
| 2 | **Ekstremt vejr** | Storm, snefald eller hedebølge. Sigt 10–30 ft. Rejsehastighed halveres. |
| 3 | **Kraftig regn/sne** | Fakler slukkes, \-2 på synsbaserede checks. |
| 4–5 | **Tåget/Overskyet** | Sigtbarhed 100 ft, fugtigt og køligt. |
| 6–8 | **Mildt vejr** | Typisk for årstiden. Ingen særlige effekter. |
| 9–10 | **Solrigt/Klart** | \+1 på Morale og Reaction Rolls den dag. |
| 11 | **Blæsende/Varmt** | Missile attacks \-1; vind påvirker flyvende væsner. |
| 12 | **Omslag** | Rul igen – vejret skifter dramatisk i løbet af dagen.  |

## 

## Temperaturvariation

Rul **1d4** for sæsonens daglige variation.

| Sæson | 1 | 2 | 3 | 4 |
| ----- | :---: | :---: | :---: | :---: |
| Forår/Efterår | Frost | Køligt | Lunt | Solrigt |
| Sommer | Koldfront | Overskyet | Varmt | Hedebølge |
| Vinter | Streng frost | Frost | Tø | Tåge |

### Effekter:

* Frost: \-1 bevægelse; risiko for glatte overflader.

* Hedebølge: Vandforbrug fordobles (RC s. 88, forsyninger).

## 

## Langtidsmønstre

Rul **1d6** én gang pr. uge.

| Slag | Ugentligt mønster |
| ----- | ----- |
| 1–2 | Stærkt ustabilt vejr (ændrer sig dagligt). |
| 3–4 | Normalt for årstiden. |
| 5–6 | Ualmindeligt stabilt (solrigt/regnfuldt hele ugen). |

## 

## Vejr og magi

| Situation | Effekt |
| ----- | ----- |
| Storm/torden | Lightning Bolt & Call Lightning \+1 skade pr. terning. |
| Kraftig vind | Fly/Levitate kræver DEX-check for at holde kurs. |
| Regn/sne | Wall of Fire \-1 skade pr. terning; Visibility halveres. |

## Stemningsbeskrivelser (brug som farve)

* “Vinden fra nord smager af jern og kulde.”

* “Regnen pisker mod dit skjold som en utålmodig tromme.”

* “Dalhulåen er steget to fod i nat – og broen knager under vægten.”

* “Tågen sluger landsbyen, og kun kirkeklokken bryder stilheden.”

**Anvendelse:** Brug tabellen hver gang en ny dag begynder, eller når spillerne bevæger sig til et nyt område. Notér vejret kort på din session-log, da det påvirker rejsetid, sigt og stemning.
