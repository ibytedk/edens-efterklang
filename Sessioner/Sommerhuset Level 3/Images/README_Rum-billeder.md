# Rum-billeder til Niveau 3: Det Øverste Tempel

Der er genereret **ét billede per rum** (R01–R50) med fælles visuel stil:

- **Underjordisk tempel**, 15–20 m under jorden
- **Ingen tændte fakler på væggene** – alt lys kommer fra spillernes/monstrenes fakler
- **Hvid, grå og sort marmor** – vægge, gulv, loft
- **Ét fakkellys** i hvert billede, der kaster en lille pool af varmt lys; resten i dyb skygge
- **Grimdark fantasy**, moody, dramatisk

## Placering af filer

Billederne er genereret og gemt i Cursor-projektets **assets**-mappe:

```
C:\Users\info\.cursor\projects\j-Shared-drives-Edens-Efterklang\assets\
```

For at bruge dem i kampagnen kan du **kopiere** dem hertil:
`Sessioner/Sommerhuset Level 3/Images/`
