## Using This Book

This manuscript is written as a **Rules Cyclopedia overlay**, not as a replacement combat system. Wherever the Rules Cyclopedia already provides a working procedure, that procedure remains in force. Wherever the Rules Cyclopedia is silent on tournament practice, the new rule is marked **Tournament Extension** and should be read as a compatible addition, not as hidden canon. Within the named tournament events, appendices, and hosting procedures, any scoring, victory, incident, scheduling, or budget method not directly restating an RC rule is likewise a **Tournament Extension**.

### Source Policy

- Core combat, initiative, morale, attack rolls, movement, encumbrance, and weapon use remain those of the **Rules Cyclopedia** (RC pp. 102-114).
- Weapon performance remains grounded in **Weapon Mastery** and the normal weapon tables (RC pp. 75-82; pp. 62-69).
- Mounted handling remains grounded in **Riding**, **Animal Training**, **Veterinary Healing**, barding, and mount load rules (RC pp. 68-70; pp. 82-84; p. 133).
- Formal bouts default to **Nonlethal Combat** and may escalate into **Death's Door** procedures only when the event turns grave or when a deadly option is declared (RC pp. 266-267).
- Hiring troops, specialists, and support staff uses the RC economy as the price floor and reference scale (RC pp. 132-133).

### Table Assumptions

This sourcebook assumes the following optional RC rules are in use:

- **Weapon Mastery** (RC pp. 75-81)
- **General Skills** (RC pp. 81-88)
- **Advanced Encumbrance** (RC p. 88)
- **Morale** (RC pp. 102-103)
- **Two Weapons Combat** (RC p. 110)
- **Unarmed Combat** (RC pp. 110-114)
- **Ability Checks** (RC p. 143)
- **Ability Scores and Saving Throws** (RC p. 266)
- **Keeping Characters Alive** (RC pp. 266-267)

### Design Principles

1. The tournament is a **social machine**, not merely a string of attack rolls.
2. Formal combat favors **skill, reputation, and spectacle** while still resting upon real danger.
3. The **marshal** matters as much as the champion.
4. A well-run tournament can be a **treasury engine**, a **political lever**, or a **prelude to feud**.
5. The best rules are those which let a DM move from procession to challenge to riot without changing books.

### A Note on Lance Rights

The lance remains a restricted weapon. Fighters, dwarves, and elves may use the **Lance Attack** maneuver; mystics may use the lance as a weapon but do not gain the Lance Attack maneuver; other human classes do not use the weapon effectively in formal charging play unless the DM deliberately opens that privilege by campaign law or special training (RC p. 64; RC pp. 104-105). This book does not silently widen that right.

### Formal and Deadly Modes

Unless an event explicitly states otherwise, tournament bouts are assumed to be fought under **formal rules**:

- Real attack rolls are made.
- Real damage is rolled.
- Damage is split according to **Nonlethal Combat**: one-quarter actual damage, remainder nonlethal (RC p. 267).

If a bout is declared **deadly**, ignore the formal split and use ordinary RC damage.

### Three Ways to Use This Book

This book is meant to be used in three distinct fashions:

- **Entrant Play:** A player character enters an event, follows the event format, and resolves the bout under ordinary RC combat procedure plus the listed tournament extensions.
- **Player Host Play:** A player character with money, permission, attendants, and ambition may proclaim a festival, hire officers, fund the purse, and use Chapter 7 as an administrative sequence.
- **Referee Festival Play:** The DM may build a whole tournament as a political event, a public diversion, a military inspection, or an NPC venture, using the quick procedures in Chapter 7 and the appendices.

If speed is wanted, begin with the step-by-step procedures in **Hosting a Tournament** and only turn to the detailed event entries when an actual bout begins.

### Start Here: Run a Petty Fair Tonight

If this book is being used for the first time, do not begin with a royal championship. Run one small formal festival: one day, one rope ring, one herald, one marshal, eight entrants, one main foot event, and perhaps one short joust exhibition if the campaign already has trained mounts and lawful lance-users. That is enough to teach the whole machine.

Use the following first-use package:

| Element | First-Use Default |
| --- | --- |
| Scale | **Petty Fair** |
| Main Event | **Sword Prize Duel** or **Axe Prize Bout** |
| Supporting Event | none, or one **Three-Pass Joust** exhibition |
| Format | **Single Elimination** |
| Mode | **Formal** only |
| Entrants | 8 foot contestants; optional 4 mounted contestants |
| Purse | 100 gp first prize, 25 gp second prize, one 10 gp honor purse |
| Social Layer | Track **Crowd Standing** only for PCs, the defending champion, and one named rival |
| NPC Resolution | Use the **Off-Stage NPC Bout Procedure** for every bout not directly watched by the table |

Run that first festival in this order:

1. Name the host, purpose, and place.
2. Choose one main event and no more than one supporting event.
3. Name the marshal, herald, and clerk.
4. Enroll the entrants and inspect legal arms and armor.
5. Roll **Crowd Temper** once for the day.
6. Pair the first round and choose which bout the table will watch in full.
7. Resolve that watched bout exactly by the event entry.
8. Resolve every other bout either in full or by the off-stage NPC method.
9. Allow recovery, advance the bracket, and run the final.
10. Pay the purse, assign Honor Marks, and roll one Political Fallout result if the referee wants a lasting consequence.

### First Use Defaults

For the first live session, use the following defaults unless a particular adventure calls for something harsher:

- use **formal mode** only
- use **single elimination** for the main event
- ignore **Crowd Standing** for unnamed NPCs
- do not use **deadly mode**, **ransom rights**, or **remounts** in the first session unless they are the central point of the scenario
- roll **Crowd Temper** once at dawn and keep that result for the day unless scandal, weather, or a princely arrival plainly changes the field
- roll incident tables only at their stated intervals; do not add extra incident rolls merely for color
- resolve all unobserved NPC bouts with the **Off-Stage NPC Bout Procedure**
- if an extra subsystem slows the table, keep the ordinary RC attack, damage, morale, and recovery procedure and add the omitted tournament layer at the next festival instead

### First Tournament by Role

If the first festival is being run by a player character, keep it narrow: one main event, one supporting event at most, one purse already secured, and only the three essential officers. If the first festival is an NPC or referee event, prepare only **4-6 notable entrants**, one hidden dispute, and one likely political consequence. The book runs best when the referee prepares a few names and motives rather than an entire imaginary census.

### What Play Looks Like at the Table

In actual use, a tournament bout is simpler than the whole manuscript may first suggest:

1. The herald states the entrants, event, and victory condition.
2. The referee checks whether the bout uses **rounds** or **passes**.
3. The combatants declare any special maneuver, salute, or challenge term.
4. The referee resolves initiative or the joust pass procedure.
5. Attack rolls, damage, and the formal split are resolved by ordinary RC procedure.
6. The event entry decides whether the hit scores **1 touch**, **2 touches**, an **unhorsing**, a **disarm**, or no score at all.
7. The marshal reviews fouls, resets distance if needed, and resumes the bout.
8. The clerk marks score, actual damage, nonlethal damage, and bracket result.

If the players remember only one principle, let it be this: **the Rules Cyclopedia handles the fighting; this book decides what counts, what is honorable, and what happens before and after the blow**.

## Tournament Fundamentals

This chapter provides the common machinery used by all events in this book.

### Entrants and Eligibility

A contestant must meet all of the following:

- He must be able to use the weapons of the event according to normal RC class rules.
- He must possess the minimum harness, mount, and attendants required by the event.
- He must submit to inspection by the marshal.
- He must declare whether he fights for **purse**, **honor**, **favor**, **ransom**, or **judgment**.

### Tournament Extension: Classes of Entry

Use the following entry classes when a host wishes to divide the field. These are not new armor rules; they are administrative categories laid over the existing RC equipment lists.

| Entry Class | Allowed Harness | Typical Weapons | Notes |
| --- | --- | --- | --- |
| Light Foot | None, leather, shield | sword, spear, axe, club, staff | Cheapest class; favored in village and fair contests |
| Middle Foot | Scale, chain, shield | sword, spear, battle axe, pole weapons | Most common noble foot class |
| Heavy Foot | Banded, plate, suit | sword, polearm, battle axe | Slow but prestigious |
| Light Horse | Riding horse, leather or scale, light barding at most | spear, sword, light lance by house rule only | Best for games of maneuver |
| War Horse | War horse, chain or plate, field barding permitted | spear, sword, lance | Standard mounted melee class |
| Grand Harness | War horse, plate or suit, field or joust barding | lance, sword, mace | Full lists and championship class |

### Heraldic Identity

Every noble or free challenger should present some visible token by which the crowd, the herald, and the judge of the field may distinguish him:

- shield pattern
- surcoat color
- pennon
- favor
- spoken style and title

If the field is crowded or anonymous, the herald may require painted shields or numbered sashes.

### Officials of the Field

Use as many of the following as the scale of the festival requires:

| Official | Function |
| --- | --- |
| High Marshal | Enforces arms, starts bouts, calls fouls, orders halts |
| Herald | Announces entrants, titles, purses, results, and appeals |
| Judge of the Field | Decides disputed outcomes and scandalous conduct |
| Clerk of the Lists | Keeps pairings, scores, and purse ledgers |
| Chirurgeon | Treats the hurt after each bout |
| Farrier / Horse-Leech | Treats lame or wounded mounts |
| Armorer | Repairs helms, shields, straps, saddle-fittings, and blunted heads |
| Steward | Collects fees, gate money, and stall rents |

### Tournament Extension: Standard Bout Sequence

Unless an event says otherwise, formal tournament combat follows this sequence:

1. **Inspection:** Check arms, harness, straps, and whether weapons are formal or deadly.
2. **Declaration:** State the bout type, victory condition, and whether ransom is recognized.
3. **Salute:** Heraldic cry, salute to dais, and salute to opponent.
4. **Crowd Temper Roll:** Optional 2d6 roll to establish the mood of the field.
5. **Initiative and Combat:** Use ordinary RC combat rounds unless the event uses passes.
6. **Marshal's Review:** Fouls, disputed hits, broken gear, or illegal interference.
7. **Recovery:** Apply nonlethal recovery, magical healing, or withdrawal from the bracket.

### Tournament Extension: Common Procedure Clarifications

Use the following interpretations throughout the book unless a specific event overrides them:

- A **bout** is the whole contest from salute to judgment.
- A **round** is a normal RC combat round.
- A **pass** is one single run in a joust.
- A **reset** means the marshal separates the contestants to legal starting distance or stations, breaks grapples or clinches, and resumes the contest with no score change unless the event states otherwise.
- A **legal hit** is a successful hit that is not canceled by a foul, a marshal's halt, or a boundary violation.
- If a rule says **next attack**, **next check**, **next defense**, or similar, the effect applies once only and expires at the end of the next full round, pass, or social exchange if unused.
- If a **charge fails**, the combatant still moves, but gains none of the benefits of a charge, lance attack, or set spear interaction for that round or pass.
- A **shield-based defense** means only the Armor Class benefit provided by a shield.
- A side **holds the center** only if it alone has standing combatants within 10' of the marked center when the horn sounds.
- A combatant is **cast down** when his marked actual damage plus marked nonlethal damage equals or exceeds his hit points.
- A combatant or rider is **out of bounds** when his whole body, or his mount's forequarters, have passed beyond the marked boundary.

### Tournament Extension: Morale Adjustments in Team Play

Whenever these rules say that a side, banner, or team gains or loses morale:

- adjust that side's RC morale score by the stated amount
- if no duration is stated, the adjustment lasts for the rest of the bout
- morale scores may not be reduced below **2** or raised above **12**
- player-character-only teams usually ignore morale, but retainers, hirelings, banner-men, and mounts do not
- if a mount lacks a morale score, use the rider's next required **Riding** check in place of a morale check

### Crowd Temper

The crowd is neither inert nor decorative. A warm crowd lifts courage, a spiteful crowd invites rashness.

### Tournament Extension: Crowd Temper Table

Roll 2d6 before the first event of the day, or whenever scandal, rain, great bloodshed, or a princely entrance changes the air.

| 2d6 | Mood | Effect |
| --- | --- | --- |
| 2 | Riotous | All Festival Reaction Rolls suffer -2; a second 2 on the same day triggers an immediate Scandal roll and a one-bout delay |
| 3-4 | Sullen | Purse collection falls by 20%; Applause Checks suffer -1 |
| 5-6 | Cold | No modifier |
| 7-8 | Fair | No modifier; ordinary day |
| 9-10 | Eager | Applause Checks gain +1 |
| 11 | Fervent | One favored side gains +1 morale in team events |
| 12 | Exultant | Gate and wagering rise by 25%; double the number of unsolicited challenges or invitations the referee introduces that day |

Suggested modifiers:

- +1 if the host spent lavishly on music, banners, and public victuals
- +1 if a famous champion is present
- -1 if yesterday ended in death or proven cheating
- -1 in relentless rain or bitter dust

### Tournament Extension: Crowd Standing, Applause Checks, and Festival Terms

Use these rules whenever a table result mentions **favor**, **applause**, **crowd score**, **crowd-related roll**, **favored side**, **challenge rights**, or **call-out rights**.

#### Crowd Standing

- Track **Crowd Standing** separately for each notable entrant or team.
- Default Crowd Standing is **0** at the start of each festival day.
- A reigning champion, beloved local, or splendidly heralded noble may begin at **+1**.
- A proven cheat, hated outsider, or publicly disgraced entrant may begin at **-1**.
- Crowd Standing normally ranges from **-3** to **+3**.
- Crowd Standing never modifies attack rolls, damage rolls, Armor Class, saving throws, initiative, or Weapon Mastery unless a rule explicitly says otherwise.

| Crowd Standing | Effect |
| --- | --- |
| -3 to -2 | -1 on Applause Checks and Festival Reaction Rolls involving that entrant or team |
| -1 to +1 | No direct modifier |
| +2 to +3 | +1 on Applause Checks and Festival Reaction Rolls involving that entrant or team |

#### Applause Checks

- An **Applause Check** is a **Charisma check** or an **Acting, Music, Singing, or Storytelling** skill roll made during salutes, boasts, victory speeches, graceful recoveries, banner displays, gift presentations, or similar public show.
- Success raises Crowd Standing by **1**.
- Failure has no effect.
- Failure by **5 or more** lowers Crowd Standing by **1**.
- When the Crowd Temper Table says applause checks are harder or easier, apply that modifier directly to the check.

#### Festival Reaction Rolls

- A **Festival Reaction Roll** is any ordinary RC reaction roll made for nobles, officials, sponsors, prospective patrons, challengers, or the crowd as a body during the festival.
- Apply the speaker's normal Charisma adjustment first and then apply Crowd Standing.
- Whenever these rules mention a **crowd-related roll** or **crowd roll**, use the next Applause Check or Festival Reaction Roll involving that entrant or team.
- A gain of **crowd score** means **+1 Crowd Standing**, not combat points.
- A gain of **favor** means **+1 Crowd Standing** unless another specific effect is stated.
- In a team event, the **favored side** is the side with the higher Crowd Standing. If tied, neither side is favored.

#### Challenge Rights, Call-Out Rights, and Honor Purses

- A **challenge right** lets the winner issue one lawful challenge to an eligible entrant in the same class before the day ends. If accepted, the bout is scheduled in the next open slot or on the next festival day without an additional entry fee.
- A **call-out right** is the same privilege, but it must be declared publicly before herald and crowd.
- An **honor purse** is a minor supplementary award of **10-50 gp** or an equivalent gift, granted for gallantry, style, or crowd favor rather than for the main victory.

### Fouls and Illegal Conduct

In a formal tournament, not every successful act is lawful.

### Tournament Extension: Foul Table

Roll or choose as needed.

| 1d10 | Foul | Usual Penalty |
| --- | --- | --- |
| 1 | Early start before the signal | Warning on first offense; lost point thereafter |
| 2 | Strike after the marshal's halt | Lost bout unless openly accidental |
| 3 | Deliberate strike on horse in a formal lists event | Disqualification |
| 4 | Unblunted or tampered point in a formal event | Disqualification and possible arrest |
| 5 | Grappling in a no-grapple bout | Lost point or forced separation |
| 6 | Passing beyond boundary and striking from the side | No score; reset |
| 7 | Hidden magic or active spell aid | Disgrace, forfeit, and possible confiscation |
| 8 | Servant interference | Loss of pass or team penalty |
| 9 | Refusal to answer lawful challenge after enrollment | Strike from the rolls |
| 10 | Heraldic fraud | Purse seized pending judgment |

### Recovery Between Bouts

Use the RC nonlethal recovery procedure as the default:

- Half lost nonlethal damage returns after **2d6 x 10 minutes**.
- The rest returns after an equal additional period.
- Actual damage remains until healed normally (RC p. 267).

### Tournament Extension: Recovery Bands

For ease at the table, sort contestants into bands after each bout:

| Condition | Meaning |
| --- | --- |
| Fresh | Less than 25% total hp marked in actual + nonlethal damage |
| Winded | 25%-49% marked |
| Hurt | 50%-99% marked; the marshal may require a chirurgeon's inspection |
| Cast Down | Total marked hp equals or exceeds hit points; combatant is out until recovered |

### Ability Checks in the Lists

When an action falls outside the attack roll itself, use an ability or skill check:

- **Dexterity / Riding** for keeping seat, guiding a mount, avoiding entanglement (RC pp. 82-83; RC p. 143)
- **Strength** for wrenching free a lodged weapon, dragging a foe, forcing a gate (RC p. 143)
- **Charisma / Leadership** for steadying followers or team retainers (RC p. 83; RC p. 103)
- **Charisma / Bargaining** for purse haggling and challenge terms (RC p. 83)
- **Charisma / Acting, Singing, Storytelling, Music** for ceremony, favor-winning, and public display (RC pp. 82-84)
- **Wisdom / Animal Training** or **Intelligence / Veterinary Healing** for mount care outside the bout (RC pp. 83-84; p. 133)

### Weapon Mastery in Tournament Play

Weapon Mastery bonuses, extra range, defensive benefits, multiple attacks, and special effects remain in force whenever the combatant uses a weapon he has mastered (RC pp. 75-81; RC pp. 104-114). This book never replaces those rules.

### Tournament Extension: Scoring Touches

In any event fought **to touches** rather than to collapse, a **scoring touch** is a successful legal hit that inflicts at least 1 point of total rolled damage before the nonlethal split is applied. Some events award more than one touch for a disarm, clear break, or unhorsing.

## Footman Melee

Foot contests are the backbone of every serious tournament. They are cheaper than mounted sport, attract bold men of lesser estate, and give the marshal many chances to test rules, discipline, and crowd control before the lists are opened.

### Shared Footman Procedures

- Initiative uses the normal RC combat sequence (RC p. 102).
- Formal foot bouts use nonlethal damage unless declared deadly (RC p. 267).
- A combatant may use **Parry**, **Disarm**, **Smash**, **Fighting Withdrawal**, and other legal maneuvers if he normally possesses them (RC pp. 103-105).
- Two-weapon fighting remains possible only where the event allows it (RC p. 110).
- Unarmed attacks and wrestling are usually barred unless the event is a grapple prize or the marshal declares the bout fallen into disorder (RC pp. 110-114).

### Footman Incident Table

### Tournament Extension: Footman Incident Table

Roll 1d12 at the start of round 3, and every second round thereafter in any long foot bout or melee.

| 1d12 | Incident |
| --- | --- |
| 1 | Loose sand: all charges fail this round, though movement still occurs |
| 2 | Shield strap twists: next shield-based defense is lost until the wearer spends a round adjusting it |
| 3 | Helm slips: -1 to next attack roll unless adjusted; adjustment costs the combatant his attack for one round |
| 4 | Splintered haft: next spear or axe hit checks for breakage on 1-2 on 1d6 |
| 5 | The crowd presses the rail: marshal warns; a second such result in the same bout halts the bout for one round |
| 6 | Taunt from the dais: morale check for retainers in team play |
| 7 | Sun-glare: missile and thrown attacks suffer -1 this round |
| 8 | Sudden wet ground: running and charges require Dex or Acrobatics check; failure reduces movement to a cautious half-move |
| 9 | A favor is thrown: one named combatant gains +1 on his next Applause Check or Festival Reaction Roll |
| 10 | Blood in the eyes: first injured combatant this round suffers -1 to hit next round |
| 11 | Marshal's horn: pause for separation; grapples are broken and the combatants are reset 5' apart |
| 12 | Noble challenge from the rail: winner gains one immediate bonus challenge right after the bout |

### Sword Prize Duel

#### Eligible Combatants

- Any class allowed to use a one-handed sword by normal RC class rules.
- Shield use is permitted.
- A thief may enter only if the harness class allows leather or lighter armor.

#### Legal Arms and Armor

- Short sword, normal sword, bastard sword one-handed
- Shield optional
- Harness up to plate in standard prize lists
- Suit armor only if the host has declared a heavy duel class

#### Arena Requirements

- A roped square at least 20' by 20'
- Two marshals on opposite corners
- One herald and one clerk

#### Pre-Bout Procedure

1. Inspect blades and confirm blunted or rebated edges.
2. Declare victory as **Three Touches**, **Five Touches**, or **Down and Out**.
3. Roll crowd temper if the duel opens the day or follows scandal.

#### Round/Pass Procedure

- Fight by normal RC rounds.
- No pass structure is used.
- A combatant forced to retreat out of the square loses 1 touch unless the event is **Down and Out** only.

#### Scoring

- Scoring touch: 1
- Successful disarm: 2
- Forced yield: automatic victory
- Opponent reduced to 0 total marked hp: automatic victory

#### Victory

- First to 3 or 5 touches, as declared; or
- Opponent yields; or
- Opponent is cast down and cannot continue

#### Mishaps

- On a natural 1 with a sword, roll 1d6; on 1 the combatant drops the weapon.
- On any disputed touch, the marshal may cancel the point and reset distance.

#### Random Incidents

- Use the **Footman Incident Table**.

#### Aftermath

- Winner gains purse, bracket advance, or right of challenge.
- Loser may remain honorable if he was not forced from the square or disarmed more than once.

### Spear Barrier Bout

This is the cleanest form of foot tourney for disciplined men. The barrier reduces wild circling and makes the set spear rule a true matter of nerve and timing.

#### Eligible Combatants

- Any class allowed spear, javelin, trident, pike, polearm, or lance on foot
- Best suited to fighters, dwarves, elves, and mystics

#### Legal Arms and Armor

- Spear, pike, polearm, or foot-held lance
- Shield permitted only if the chosen weapon allows it
- Harness up to plate
- No missile weapons

#### Arena Requirements

- A waist-high wooden barrier or rail between contestants
- Minimum lane length of 15'

#### Pre-Bout Procedure

1. Declare whether the bout is **Three Touches** or **Set and Break**.
2. Mark the barrier lanes.
3. Announce whether overhand strikes are legal or whether all play is thrust-only.

#### Round/Pass Procedure

- Normal RC rounds are used.
- If a combatant spends the round stationary and braced, he may declare **Set Spear vs. Charge** before contact, exactly as in RC play (RC pp. 104-105).
- Charges require a 20-yard run in ordinary RC terms; since barrier bouts are shorter, the host must declare whether a short formal rush counts as a charge.

#### Scoring

- Scoring thrust: 1
- Successful set against charge: 2
- Disarm over or around the barrier: 2
- Broken weapon from legal pressure: 1 to the breaker, plus reset

#### Victory

- First to the declared touch total; or
- Opponent loses weapon and cannot arm himself in one round; or
- Opponent yields

#### Mishaps

- Weapon lodged in the barrier: Strength check or lost next round
- Splintered shaft: replace weapon, lose initiative next round

#### Random Incidents

- Use the **Footman Incident Table**; on 4, 8, or 11 apply it to the barrier first.

#### Aftermath

- Spear bouts often produce challenge rights. A fighter who wins two barrier bouts in one day gains +1 on the next Festival Reaction Roll involving his name at that same festival.

### Axe Prize Bout

Axe play is shorter, louder, and more feared than sword play. It suits men of strong arm and little patience.

#### Eligible Combatants

- Any class allowed hand axe or battle axe

#### Legal Arms and Armor

- Hand axe or battle axe only
- Shield optional
- No plate or suit armor unless the host wishes a heavy class

#### Arena Requirements

- Open circle, 25' across
- Clear footing; no barrier

#### Pre-Bout Procedure

1. Inspect hafts and heads.
2. Declare whether throws are legal.
3. Declare touch count or **Down and Out**.

#### Round/Pass Procedure

- Normal RC rounds.
- Thrown hand axes use normal RC attack and range rules (RC p. 64).
- A battle axe may not be thrown unless the combatant's Weapon Mastery permits it (RC pp. 77-81).

#### Scoring

- Clean hit: 1
- Shield break or forced drop: 2
- Unarmed knockdown from shield rush or wrestling spill: 1 if the event permits close roughness

#### Victory

- First to 3 touches in a light prize; 5 in a heavy prize
- Or opponent yields, is disarmed twice, or is cast down

#### Mishaps

- If the axe head loosens, the combatant attacks at -2 until the marshal halts or the weapon is changed
- If a thrown axe leaves the ring, no score is possible that round

#### Random Incidents

- Use the **Footman Incident Table**.

#### Aftermath

- Axe winners earn a rough reputation. Apply +1 to Intimidation attempts made at the same festival, but -1 to delicate courtly appeals before the high table.

### Small Foot Melee

This event is fought by sides of 3 to 12 men and is the best way to test discipline before larger team play.

#### Eligible Combatants

- Any legal foot entrants of the declared harness class

#### Legal Arms and Armor

- Any legal foot arms for the declared class
- Missile weapons are usually barred

#### Arena Requirements

- A ring or yard at least 40' across
- Team colors clearly marked

#### Pre-Bout Procedure

1. Teams declare captain.
2. Captains state primary arms and reserve arms.
3. Marshal states whether fallen men may be rescued or must crawl clear.

#### Round/Pass Procedure

- Fight by ordinary RC rounds.
- Team retainers and NPC entrants use morale rules if applicable (RC pp. 102-103).
- When the first team member falls on either side, check team morale if the combatants are NPCs or retainers.

#### Scoring

- Each enemy cast down or yielded: 1
- Enemy captain yielded or captured: +2
- Team still holding center at bout end: +1

#### Victory

- Team with the greater score after the declared round limit; or
- First side wholly broken, yielded, or cast down

#### Mishaps

- If a captain falls, the team must either spend its next round closing around him or lose 1 morale
- Friendly weapon entanglement: if two adjacent allies both roll natural 1 in the same round, both lose any remaining attacks that round

#### Random Incidents

- Use the **Footman Incident Table**.

#### Aftermath

- Winning captain may immediately call out another small team or claim an honor purse.

### Grand Foot Melee

This is the older, harsher form: large bodies of men struggling for glory, prisoners, and exhaustion.

#### Eligible Combatants

- Any foot entrants accepted to the grand class

#### Legal Arms and Armor

- All legal foot arms except missile volleys, unless the host specifically allows them
- Polearms, spears, swords, axes, and shields are common

#### Arena Requirements

- Broad field, fenced commons, or enclosed market square
- At least four marshals
- Chirurgeon and litter-bearers on hand

#### Pre-Bout Procedure

1. Divide the field into banners, sides, or temporary companies.
2. Mark rescue boundary and neutral ground.
3. Announce whether ransom and prisoner-taking are recognized.

#### Round/Pass Procedure

- Fight by ordinary RC rounds.
- Every third round, each NPC banner makes a morale check if it has suffered casualties, lost a captain, or been driven back (RC pp. 102-103).
- Every fifth round, the marshal may halt the field for water, prisoner removal, or scandal control.

#### Scoring

- Enemy cast down or yielded: 1
- Enemy standard seized: 3
- Enemy captain yielded: 3
- Holding the center at the final horn: 2

#### Victory

- Highest score at the final horn; or
- Total collapse of one side

#### Mishaps

- Lost standard: immediate morale check for NPC companies
- Opened visor or broken strap: AC worsens by +1 until adjusted

#### Random Incidents

- Use the **Footman Incident Table**, plus roll once on the **Scandal Table** at round 5 and every fifth round thereafter.

#### Aftermath

- Grand melees are breeding grounds for grudges. Any captain who loses standard, purse, and face in one afternoon is likely to return later with a private challenge.

## Mounted Melees

Mounted tourney combat is not the joust. It is rougher, broader, and often nearer to battlefield work.

### Shared Mounted Rules

- A riding animal used under stress may require a **Riding** skill roll before the rider can attack effectively from the saddle (RC p. 83).
- A war horse may charge; its rider may use the lance for double damage on a proper charge (RC p. 70; RC pp. 104-105).
- Riding horses are fast but not made for battle work; war horses are slower but fight, endure pressure, and charge well (RC p. 70).
- Use barding, load, and encumbrance normally; an overburdened horse is slower even on the festival field (RC pp. 68-70).
- If a mount **panics**, the rider must immediately make a Riding check. On failure, the mount withdraws toward the nearest boundary at full movement, makes no attack that round, and scores normally if its flight leaves the field. **Tournament Extension**
- A team in **disorder** loses charge bonuses and formation benefits until it regroups successfully. **Tournament Extension**

### Tournament Extension: Mount Readiness Bands

| Condition | Effect |
| --- | --- |
| Fresh | No penalty |
| Sweating | After 3 hard rounds or passes; next Riding check at -1 |
| Blown | After 6 hard rounds or repeated failed checks; movement drops one band |
| Distressed | After injury, panic, or overloading; must check morale before charging again |

One movement band means reduce the mount's current encounter movement to the next lower practical RC rate, such as **240' to 120'**, **120' to 90'**, or **90' to 60'**. **Tournament Extension**

### Tournament Extension: Formation Entry Table

Before the first clash of a mounted melee, each side chooses one formation.

| Formation | Effect on First Clash |
| --- | --- |
| Line | +1 to first legal attack roll if frontage is clear |
| Wedge | +1 morale on first contact; -1 Riding on bad ground |
| Open Order | No attack bonus, but +2 on regroup checks |
| Echelon | One chosen flank gains +1 on its first legal attack roll on first contact |

### Mounted Skirmish

#### Eligible Combatants

- Any rider lawfully mounted for the event
- Best restricted to war horses unless the host means the bout to be light and playful

#### Legal Arms and Armor

- Spear, sword, mace, club, battle axe, or lance if the rider is entitled to it
- Shield optional
- No missile weapons unless expressly declared

#### Arena Requirements

- Open yard or field
- Minimum charge run of 20 yards in at least one direction

#### Pre-Bout Procedure

1. Inspect tack, girths, and stirrups.
2. State whether the bout is **to touches**, **to unhorsing**, or **to casts down**.
3. Choose starting formations if sides are present.

#### Round/Pass Procedure

- Use ordinary RC rounds.
- A rider who fails a required Riding check may move and defend, but cannot make a clean attack that round.
- Lance attacks must satisfy the normal charge requirement (RC pp. 104-105).

#### Scoring

- Clean mounted hit: 1
- Enemy forced to lose seat but remain mounted: 2
- Enemy unhorsed: 4
- Enemy mount panics and flees boundary: 2

#### Victory

- First to declared points; or
- Last mounted side remaining; or
- Opponent yields

#### Mishaps

- Fall from saddle in formal play inflicts **1d6 nonlethal damage** on turf or **1d6 total damage split by formal rules** on hard ground. **Tournament Extension**
- If horse and rider both fall, the marshal may suspend the bout at once.

#### Random Incidents

- Use the **Mounted Incident Table**.

#### Aftermath

- A rider unhorsed twice in one day may not enter the grand championship unless the host is desperate for spectacle.

### Team Mounted Melee

#### Eligible Combatants

- Teams of 3 to 12 mounted entrants

#### Legal Arms and Armor

- As declared by class: light, war horse, or grand harness

#### Arena Requirements

- Broad field with marked boundaries and one neutral reform line

#### Pre-Bout Procedure

1. Appoint captain.
2. Choose formation.
3. Declare whether lances are only for first contact or legal throughout.

#### Round/Pass Procedure

- Use ordinary RC rounds.
- After each clash, riders may break, wheel, and reform.
- At the end of round 3 and every third round thereafter, each team may make one free regroup attempt under its captain: Leadership or the captain's Charisma check restores order after disorder. **Tournament Extension**

#### Scoring

- Enemy unhorsed: 2
- Enemy captain unhorsed or yielded: 4
- Enemy driven across boundary in disorder: 2
- Banner or token seized from moving rider: 3

#### Victory

- Greatest score at horn; or
- One side wholly broken

#### Mishaps

- Captain unhorsed: immediate morale check for NPC teammates
- Failed regroup: side loses next chance to charge

#### Random Incidents

- Use the **Mounted Incident Table**.

#### Aftermath

- Team melees settle boasting rights better than lawsuits, but not always more cheaply.

## Jousting

The joust is the flower of mounted display: narrow, exacting, easy for the crowd to understand, and ruinously expensive to host badly.

### The Lists

A proper lists course should provide:

- two lanes
- a dividing rail or marked center
- at least 20 yards of charging room before impact
- clear run-out space beyond the meeting point
- marshals at each end

### Tournament Extension: Lists Conditions Table

Roll once per session of jousting, or whenever the weather changes.

| 1d8 | Condition | Effect |
| --- | --- | --- |
| 1 | Hard-packed earth | Falls are harsher; add +1 actual damage on spills |
| 2 | Good turf | No modifier |
| 3 | Sanded lane | +1 on saddle checks |
| 4 | Churned center | -1 on second and later passes |
| 5 | Wet ground | Riding check required before each pass |
| 6 | Dusty lane | First pass clear, later passes -1 to hit at long glare |
| 7 | Crosswind | -1 to light lances and pennon-heavy riders |
| 8 | Broken rail patch | Any rider who drifts makes an immediate foul check |

### Tournament Extension: Lance Quality Table

Before a bout, the DM may roll 1d8 for each issued lance lot.

| 1d8 | Lance Quality | Effect |
| --- | --- | --- |
| 1 | Green wood | -1 to hit; breaks on any legal hit |
| 2 | Heavy ash | +1 damage; -1 on saddle checks made by the striker after impact |
| 3-5 | Serviceable | No modifier |
| 6 | Well-balanced | +1 to hit |
| 7 | Tourney-blunted | Break range improves by one step in formal lists; -1 actual damage after split |
| 8 | Prize lance | +1 to hit; break range improves by one step on any legal hit |

### Declaring the Joust

Before the first pass, the herald must announce:

- number of passes
- whether points or outright unhorsing decides the bout
- whether broken lances are scored
- whether a remount is allowed after a fall
- whether shield strikes only are counted legal

### Tournament Extension: Joust Clarifications

- A rider who reaches contact without a lawful charge attacks only as with an ordinary spear thrust: no double damage, no improved break chance, and a maximum score of **1** for the pass.
- If the host declares **shield strikes only**, hits on helm, body, or horse do not score, though horse hits remain fouls in formal play and body hits still inflict damage in deadly play.
- If a remount is allowed after a fall, the fallen rider misses the next pass-equivalent interval and suffers **-1 on his next control check** after remounting.
- Unless the host has declared some harsher local custom, an unhorsed rider in a formal joust suffers **1d6 nonlethal damage** from the spill; on **hard-packed earth**, add **+1 actual damage** to that spill after rolling the die.

### Tournament Extension: The Pass

Each joust pass is resolved as follows:

1. **Mount and Settle:** Riders take stations; tack, visor, and lance are checked.
2. **Line Readiness:** Apply lane condition modifiers and any fatigue from prior passes.
3. **Charge:** Both riders move. If one cannot make a lawful charge, he cannot use a true lance attack.
4. **Control Check:** If conditions demand it, make Riding checks before impact.
5. **Strike:** Eligible riders make simultaneous lance attacks.
6. **Damage:** Roll ordinary lance damage, double it for a true charge, and then apply adjustments according to RC procedure (RC pp. 104-105).
7. **Formal Split:** If the joust is formal, split the damage into actual and nonlethal using RC nonlethal rules (RC p. 267).
8. **Break Check:** Roll on the lance break rule below.
9. **Saddle Check:** Apply the shock of impact.
10. **Score:** Award points.

### Tournament Extension: Lance Break Rule

Whenever a legal hit is scored in a formal joust, roll 1d6.

- Base break on **1-3**
- If total doubled damage before the nonlethal split is **8+**, break on **1-4**
- If total doubled damage is **12+**, break on **1-5**
- Modify by lance quality if any

A broken lance is worth extra honor because it is visible, audible proof to the crowd.

A one-step improvement to break range means **1-3 becomes 1-4**, **1-4 becomes 1-5**, and **1-5 becomes 1-6**. **Tournament Extension**

### Tournament Extension: Saddle Check Table

After suffering a legal hit in the joust, the struck rider must make a **Riding** skill check. If he lacks the skill, he instead makes a **Dexterity check**. Apply the following penalties by impact:

| Doubled Damage Before Split | Check Modifier | Result of Failure |
| --- | --- | --- |
| 1-7 | None | Stays mounted; no extra effect |
| 8-11 | -1 | Stays mounted, but loses next pass initiative and suffers -1 to hit on the next pass |
| 12-15 | -2 | Nearly unhorsed; if failed by 5+, unhorsed |
| 16-19 | -4 | Unhorsed on failure |
| 20+ | -6 | Unhorsed on failure; stunned on failure by 5+ |

If the rider is in suit armor and mounted with assistance, no special penalty applies merely for the armor; if he mounted in haste or his straps are poor, the DM may apply an additional -1 or -2. This reflects RC's treatment of suit armor as difficult to manage without help (RC pp. 68-69).

### Tournament Extension: Joust Scoring Table

| Result | Score |
| --- | --- |
| Legal hit, no break | 1 |
| Legal hit and lance breaks | 2 |
| Legal hit of 12+ doubled damage | 3 |
| Opponent fails saddle check, but the declared format does not treat that failure as immediate unhorsing | 3 |
| Opponent unhorsed | 5 and immediate bout victory unless the host has declared a cumulative championship |

Award only the **single highest applicable score** from the table for each pass unless the host explicitly declares cumulative scoring before the bout. **Tournament Extension**

### Three-Pass Joust

#### Eligible Combatants

- Fighters, dwarves, and elves by right
- Mystics only if the host allows them to thrust in the lists without Lance Attack privilege
- Other classes only by explicit campaign law, household training, or host decree

#### Legal Arms and Armor

- Lance only for the pass
- Sword, mace, or dagger at saddle only for emergencies
- Shield mandatory
- Plate or suit armor customary
- War horse required for serious competition
- Field or joust barding optional but common in high play

#### Arena Requirements

- Proper lists with dividing rail
- Run-up and run-out
- Two lance attendants per rider

#### Pre-Bout Procedure

1. Declare formal or deadly mode.
2. Inspect lances, helm, saddle, girths, and barding.
3. Roll lists condition if not already known.
4. State whether three passes are the whole bout or whether tied riders go to sword after.

#### Round/Pass Procedure

- Resolve exactly by **The Pass** procedure above.
- Each pass is simultaneous unless an incident delays one rider.

#### Scoring

- Use the **Joust Scoring Table**.

#### Victory

- Higher score after three passes; or
- Unhorsing if the host has declared it decisive; or
- Sword-at-saddle or foot follow-up if tied and the event so states

#### Mishaps

- Broken saddle, snapped girth, or lost stirrup may end the bout at the marshal's discretion
- A rider who crosses the rail or strikes the horse commits a foul

#### Random Incidents

- Use the **Joust Incident Table** beginning with pass two

#### Aftermath

- The winner advances, claims purse, or gains right of challenge
- A rider unhorsed in open disgrace may still regain **1 Crowd Standing** if he rose promptly and saluted cleanly

### Challenge Joust

#### Eligible Combatants

- As in the Three-Pass Joust

#### Legal Arms and Armor

- As declared by the host

#### Arena Requirements

- Proper lists

#### Pre-Bout Procedure

1. Challenger names stake.
2. Defender names acceptance.
3. Herald records whether the issue is purse, favor, or standing.

#### Round/Pass Procedure

- Fight until one side reaches the declared point total, scores an unhorsing, or yields.

#### Scoring

- Usually played to **7 points**

#### Victory

- First to declared points or decisive unhorsing

#### Mishaps

- Same as Three-Pass Joust

#### Random Incidents

- Use the **Joust Incident Table**

#### Aftermath

- Challenge jousts create grudges faster than bracket play. The loser often seeks rematch terms before sunset.

---

### Grand Championship Joust

#### Eligible Combatants

- Finalists or seeded nobles only

#### Legal Arms and Armor

- Grand harness
- War horse
- Field or joust barding

#### Arena Requirements

- Full princely lists
- Heralds, judges, musicians, chirurgeons, spare lances, reserve tack

#### Pre-Bout Procedure

1. Roll crowd temper with +1 if the purse is great and the stands are full.
2. Present each champion by style, lineage, and prior victories.
3. Declare the number of passes: usually 5.

#### Round/Pass Procedure

- Resolve as a series of passes.
- After pass 3, either rider may petition for fresh lance stock; in princely or royal lists it is normally granted unless the host is **Thin** or **Disorderly** by the NPC Host Procedure.

#### Scoring

- As normal, but broken lances count heavily because they are legible to the crowd.

#### Victory

- Most points after 5 passes, unless an unhorsing ends the matter sooner.

#### Mishaps

- At this level every protest matters. The judge of the field may suspend the lists after any disputed pass.

#### Random Incidents

- Use the **Joust Incident Table** every pass after the first.

#### Aftermath

- The champion gains purse, honor, and perhaps patronage. The defeated finalist often gains more invitations than the winner if he gave a splendid showing.

## Hosting a Tournament

To host a tournament is to build a temporary little dominion: one part fairground, one part military camp, one part theatre, one part lawsuit.

### Tournament Extension: Player Host Procedure

When a player character wishes to hold a tournament, do not begin with attack rolls. Begin with authority, money, and officers.

1. **Gain the right to proclaim the lists.** The host must possess land-right, patron leave, temple or guild sanction, or an unlawful backer if the event is secret.
2. **Choose the purpose.** Feast, wedding, muster, ransom, reconciliation, recruitment, boasting, or judgment.
3. **Choose the scale.** Use the Tournament Scale Table below and reduce the scale at once if the character cannot support it.
4. **Lock the purse before announcing the event.** Set aside the purse plus at least half again for works, staff, feed, and breakage. If the money is not truly reserved, the proclamation is premature.
5. **Name the three essential officers.** Every lawful tournament needs a marshal, a herald, and a master of guards. One person may fill two offices in a petty fair, but never all three.
6. **Declare the program.** Choose the main event, any supporting events, the legal arms and armor, whether the mode is formal or deadly, and the victory conditions.
7. **Open entry.** Set the fee, date of arrival, and what each entrant must bring: mount, squires, colors, shield, witnesses, ransom surety, or patron token.
8. **Inspect the field one day before first combat.** Check rails, water, stabling, spare weapons, heraldic rolls, guard stations, and the purse chest.
9. **Run each festival day in order.** At dawn determine weather, crowd temper, and field condition. Hear challenges, resolve bouts, record wounds, and settle disputes before nightfall.
10. **Close the books.** Pay prizes, settle ransoms and damages, dismiss staff, roll political fallout, and record who now owes service, money, gratitude, or revenge.

One relevant skill or ability roll may be allowed at Steps 4-8 whenever the host actively directs the work: **Bargaining** to reduce costs, **Leadership** to steady staff, **Animal Training** to improve the mount lines, **Acting**, **Music**, **Singing**, or **Storytelling** to improve the public appeal, granting **+1 on the opening Crowd Temper roll for the first day** on a success, or a plain Charisma check when no better fit exists (RC pp. 82-84; p. 143).

### Tournament Extension: Referee Procedure

When the DM needs a ready tournament for play, use the following order of work:

1. **Choose the host.** Decide whether the sponsor is a PC, NPC lord, temple, guild, prince, widow, claimant, or outlaw patron.
2. **Choose motive and scale.** Decide why the event exists and how large it is meant to appear.
3. **Choose purse and event mix.** Decide the main event, the supporting events, and whether the host seeks fame, profit, or political effect.
4. **Create the notable entrants.** Prepare only a short list: 4-12 names, one or two traits each, and one mechanical edge each.
5. **Seed the festival before play begins.** Roll or choose weather, crowd temper, one scandal, and one hidden dispute.
6. **Run enrollment and inspection.** Resolve heraldry, equipment, legal arms, suspicious entrants, and late challenges.
7. **Run only important bouts in full detail.** Use complete round-by-round procedure when a PC fights, watches closely, or has money and honor riding on the result.
8. **Resolve distant or purely NPC bouts off-stage.** Use the Off-Stage NPC Bout Procedure below whenever detail would only slow the session.
9. **End each day cleanly.** Advance recovery, bracket progress, repairs, rumors, wagers, feuds, and invitations.
10. **End the festival with consequences.** Pay purses, award honors, roll political fallout, and decide which NPCs become patrons, rivals, debtors, or future challengers.

### Tournament Extension: NPC Host Procedure

When the host is an NPC or institution, determine the following in order. Choose results or roll.

1. **Motive:** Why is the host spending the money?
2. **Competence:** Is the festival orderly or shabby?
3. **Purse Reliability:** Will the winners truly be paid?
4. **Political Backing:** Who protects the event when trouble begins?
5. **Hidden Agenda:** What is the host really trying to accomplish?

### Tournament Extension: Off-Stage NPC Bout Procedure

Use this only when no player character is directly acting and the table does not want full combat detail.

1. **Find each side's Advantage Score.** Start at 0.
2. Apply the following modifiers:
   - **+2** if the combatant's normal chance to hit the foe is clearly better by 3 or more attack numbers.
   - **+1** if it is better by 1-2 attack numbers.
   - **+1** for one higher Weapon Mastery rank in the event weapon; **+2** if higher by two or more ranks.
   - **+1** in mounted events for a war horse against a riding horse or inferior mount.
   - **+1** if the combatant has the relevant general skill and the foe does not, most often **Riding** or **Leadership** (RC pp. 82-84).
   - **-1** if lightly wounded, fatigued, or recently unhorsed.
   - **-2** if at half hp or worse, badly shaken, or using damaged gear.
3. Each side rolls **1d20 + Advantage Score**.
4. Higher total wins. If tied, roll again or declare the first pass indecisive.

| Margin | Result |
| --- | --- |
| 1-2 | Narrow win; one touch, one point, or disputed edge |
| 3-5 | Clear win; ordinary victory with no lasting scandal |

| 9+ | Crushing win; apply one extra consequence appropriate to the event: Injury Severity for a hard fall, Scandal for a public uproar, or an immediate feud or rematch result in a grudge match |

### Appendix H: Worked Play Examples

These examples are not fiction. They are shortened referee transcripts showing declaration, die roll, judgment, scorekeeping, and aftermath. Use them when the table wants to see the procedure before running a live bout.

#### Annotated Example 1: A Sword Prize Duel

**Setup**

- Event: **Sword Prize Duel**
- Mode: **Formal**
- Victory Condition: **Three Touches**
- Combatant A: Sir Aldred, Fighter 6, AC 2, hp 28, THAC0 17, shield and normal sword
- Combatant B: Harl Fen, Fighter 4, AC 3, hp 24, THAC0 17, shield and normal sword
- Crowd Temper: **Fair**

**Inspection and Declaration**

1. The marshal confirms that both swords are rebated and both shields are lawful.
2. The herald announces, "Three touches, formal rules, no deadly follow-up."
3. The clerk opens one score sheet and one recovery line for each combatant.

**Round 1**

1. The referee rolls initiative for each duelist as if each were a side. Aldred rolls **5**; Harl rolls **2**. Aldred acts first (RC p. 102).
2. Aldred attacks AC 3. With THAC0 17 he needs **14**. He rolls **14** and hits.
3. Damage is **8**. Because the duel is formal, this becomes **2 actual** and **6 nonlethal** (RC p. 267).
4. The event scores any legal damaging hit as **1 touch**, so Aldred leads **1-0**.
5. Harl attacks back and rolls **11**, which misses AC 2.

**Round 2**

1. Harl wins initiative with **6** against Aldred's **3**.
2. Harl attacks AC 2. With THAC0 17 he needs **15**. He rolls **15** and hits.
3. Damage is **4**. In formal play that becomes **1 actual** and **3 nonlethal**.
4. Harl scores **1 touch**. The bout is now tied **1-1**.
5. Aldred attacks and misses.

**Round 3**

1. Aldred wins initiative with **4** against **1**.
2. Aldred declares a lawful **Disarm** attempt under RC combat maneuvers (RC pp. 103-105).
3. The attack succeeds. The marshal rules that Harl's sword is knocked clear.
4. In this event a successful disarm is worth **2 touches**.
5. Aldred's total becomes **3 touches**. The bout ends at once, even though Harl still has hit points remaining.

**Aftermath**

- Aldred has marked **1 actual** and **3 nonlethal** damage.
- Harl has marked **2 actual** and **6 nonlethal** damage.
- Harl is not cast down; he merely loses by score.
- The clerk records Aldred as winner, the recovery clock begins under RC nonlethal rules, and Aldred may claim purse, bracket advance, or a challenge right.

This example shows the book's core principle plainly: RC combat resolves the blows, while the event entry converts those blows into touches and victory.

#### Annotated Example 2: A Three-Pass Joust

**Setup**

- Event: **Three-Pass Joust**
- Mode: **Formal**
- Format Declaration: **Shield strikes only**, **unhorsing decisive**, **no remount**
- Lists Condition: **Good Turf**
- Lance Quality: **Serviceable**
- Rider A: Sir Osric, Fighter 8, AC 0, hp 34, THAC0 15, Riding, Dexterity 12
- Rider B: Dame Celene, Fighter 8, AC 0, hp 31, THAC0 15, Riding, Dexterity 13

**Pass 1**

1. Both riders mount, settle, and take legal stations.
2. Good turf requires no control check before impact.
3. Both make lawful charges.
4. Osric attacks AC 0 and rolls **11**, missing.
5. Celene attacks AC 0 and rolls **13**, also missing.
6. No legal hit means no damage, no break check, no saddle check, and no score.

**Pass 2**

1. Both riders charge cleanly again.
2. Osric attacks AC 0 and rolls **16**, hitting.
3. The lance damage totals **6**, doubled to **12** because the charge is lawful (RC pp. 104-105).
4. In formal play, that becomes **3 actual** and **9 nonlethal** damage to Celene (RC p. 267).
5. Because the doubled damage is **12+**, Osric's break range improves to **1-5**. The referee rolls **4** on 1d6, so the lance breaks.
6. Celene now makes a Riding check with a **-2** penalty from the Saddle Check Table. Her effective target is **11**, and she rolls **9**. She stays mounted.
7. Scoring is not cumulative by default. The highest applicable score this pass is **3 points** for a legal hit of 12+ doubled damage. Osric leads **3-0**.

**Pass 3**

1. Fresh lances are issued and the riders reset.
2. Celene attacks AC 0 and rolls **18**, hitting.
3. Her lance damage totals **8**, doubled to **16**.
4. In formal play, Osric takes **4 actual** and **12 nonlethal** damage.
5. The break range is again **1-5**. The referee rolls **2**, so Celene's lance breaks.
6. Osric makes a Riding check at **-4**. With Dexterity 12 his effective target is **8**. He rolls **14** and fails.
7. A failure in the **16-19** band means Osric is unhorsed.
8. Because this format treats unhorsing as decisive, Celene scores **5** and wins the bout immediately.
9. The referee rolls spill damage for the fall in the lists: **1d6 nonlethal**, result **4**.

**Aftermath**

- Celene wins despite trailing on points before the final pass.
- Osric adds the spill damage to his marked total, then may recover nonlethal loss normally.
- If Osric rises promptly, salutes cleanly, and does not quarrel with the ruling, the referee may award him **+1 Crowd Standing** under the Aftermath guidance for the event.

This example shows the whole joust sequence in order: declaration, charge, hit, doubled damage, formal split, break check, saddle check, score, and fall.

The event turns a modest surplus of **175 gp**, but only if the purse is actually paid and no riot destroys the rails.

**Step 5: Prepare Only the Important People**

The referee writes six notable entrants:

- Sir Corvin, reigning local champion
- Dame Aveline, precise lance-rider
- Brother Haim, temple-backed axe fighter
- Osbert the Red, wealthy braggart with bad discipline
- Lady Merrow's household team captain
- one disguised outsider with false heraldry

That is enough. Everyone else may be handled as ordinary NPCs.

**Step 6: Opening the Festival**

1. Dawn Crowd Temper roll: **9**, so the crowd is **Eager**.
2. Weather is dry.
3. One hidden dispute is prepared: the disguised outsider intends to challenge a sworn enemy.
4. Enrollment reveals no open problem, so the first sword bracket begins on time.

**Step 7: Run Only the Important Bouts in Full**

- The player characters enter the sword bracket, so their bouts are run round by round.
- Two NPC-only sword bouts are resolved off-stage.
- The mounted skirmish final is also run in full because a PC has money wagered on it.

**Step 8: End Day One Cleanly**

- The clerk marks all recovery bands.
- The herald announces tomorrow's joust pairings.
- One notable loser publicly complains, but no scandal roll is yet required.

**Step 9: Final Day**

1. Crowd Temper is not rerolled, because nothing severe changed overnight.
2. The joust semi-final involving the disguised outsider is resolved off-stage and produces a **6-point margin**, so it becomes a decisive, suspicious victory.
3. The final joust involving a PC is played in full.
4. The final small foot melee is played partly in summary and partly in detail whenever a PC captain acts directly.

**Step 10: Prize Giving and Consequence**

- First prize is paid in full.
- One honor purse goes to the loser of the championship joust for a splendid recovery after a fall.
- One Political Fallout roll is made: **3**, so a prince's envoy notices an otherwise minor champion and offers future service.
- The disguised outsider is later questioned by the herald, setting up the next adventure.

This is the recommended scale for first serious use of Chapter 7: large enough to feel political, small enough to run in two sessions.

#### Additional Quick Outcome Examples

These shorter examples remain useful when the referee needs only a pattern rather than a full transcript.

**Spear Barrier Bout**

- Combatant A braces and declares **Set Spear vs. Charge** before Combatant B rushes the barrier.
- Combatant A hits. The hit counts double by RC rule.
- In a touch-based event, this earns **2 touches** and likely ends a short bout.

**Axe Prize Bout**

- A hand axe is declared throwable.
- One contestant opens with a legal throw, scores **1 touch**, then closes.
- Later he forces a shield drop; that is worth **2 touches** and the marshal rules the bout over.

**Mounted Skirmish**

- Two riders on war horses engage in a small melee.
- Rider A fails a Riding check after the **Horse Shies** incident and cannot attack that round.
- Rider B lands a clean spear hit next round and later forces an unhorsing for **4 points**.

**Team Grand Melee**

- Two teams of six fight to score.
- By round 5 one captain is down, one banner is seized, and one side fails its morale roll.
- The winning side claims **3** for the banner, **3** for the captain, and later **2** for field control.

### Appendix H-2: Example Festival Session

This example is a story-based one-evening session. It shows how a referee might present the festival, how players might make choices, and how the tournament rules sit inside ordinary play rather than replacing it.

#### The Willow Market Fair

**Premise**

The player characters arrive at Willow Market on the eve of a summer fair. The reeve is sponsoring a small formal sword prize to draw merchants and to restore his standing after a poor tax season. Rumor says that one entrant, "Sir Morrow Blackleaf," bears borrowed colors and too much confidence for an unknown man.

**The Player Characters**

- Leof, a 5th-level fighter, enters the sword prize for purse and reputation.
- Anwyn, a 4th-level thief, watches the crowd and takes interest in the suspicious knight.
- Brother Cerdic, a 4th-level cleric, attends to keep the peace and to see whether the reeve is worth supporting.

**Festival Setup**

- Scale: reduced **Petty Fair**
- Main Event: **Sword Prize Duel**
- Mode: **Formal**
- Format: four-man single elimination
- Purse: **100 gp** to the winner, **25 gp** to the runner-up
- Notable NPCs: Sir Pell of the Ford, "Sir Morrow Blackleaf," and Oswin the Miller's Son

#### Scene 1: Arrival and Proclamation

**Referee**

"By noon you hear a herald's cracked voice from the market cross. A rope-ring is being staked out in the trampled grass. Painted shields hang from poles, a cooper's boy beats a kettle-drum, and the reeve's clerk calls for entrants to the sword prize: three touches, formal rules, purse in silver and gold before sunset."

Leof's player says that Leof enters at once.

Anwyn's player says that she wants to watch the noble entrants and see whether any man is wearing borrowed gentility.

Brother Cerdic's player says that he will present himself to the reeve's steward as a man willing to witness fair dealing.

**Referee Note**

The referee now does three things before any bout begins:

1. rolls **Crowd Temper**
2. determines the bracket
3. handles the social approaches

The Crowd Temper roll is **10**, so the day is **Eager**. Applause Checks gain **+1**.

The bracket becomes:

- Leof vs. Oswin
- Sir Pell vs. "Sir Morrow Blackleaf"

The reeve's steward gets a normal reaction roll toward Brother Cerdic. The result is favorable, so the cleric is invited to stand near the officials' awning and witness the purse chest.

#### Scene 2: Enrollment and Suspicion

The herald asks each entrant to show colors and name.

Leof gives his true style and plain shield.

Sir Pell gives an old and reputable lineage.

Oswin blushes, bows too low, and admits he is fighting for village honor.

When "Sir Morrow Blackleaf" steps forward, Anwyn's player says:

"I want to look closely at his shield and surcoat. I am not testing for magic. I am testing whether the thing is wrong in the way stolen finery is wrong."

**Referee Note**

There is no special heraldry skill in the book, so the referee calls for an **Intelligence check** by ordinary RC ability-check logic (RC p. 143). Anwyn succeeds.

**Referee**

"The green branch on the shield has fresh paint over older scoring. The surcoat is good cloth, but the badge has been stitched on in haste. It is not a peasant's mistake. It is a thief's repair."

Anwyn reports this quietly to Brother Cerdic, who advises the herald rather than shouting it publicly. The herald does not halt the festival yet, but marks the name for scrutiny.

This is the first important lesson of tournament play: not every matter becomes a combat rule at once. Some become pressure that ripens later.

#### Scene 3: The First Semi-Final in Full

The herald announces Leof and Oswin to the rope-ring.

Leof's player says:

"Leof salutes the reeve, salutes Oswin honestly, and raises his sword to the crowd. He wants them to see that he is not mocking the village boy."

**Referee Note**

That is an **Applause Check**. Leof makes a Charisma check and succeeds. Because the crowd is **Eager**, the check had **+1**. Leof's Crowd Standing rises to **+1**.

The bout is then run in full.

**Round 1**

- Leof wins initiative.
- He attacks and hits for **6** damage.
- In formal play, that becomes **1 actual** and **5 nonlethal**.
- That legal hit scores **1 touch**.

**Referee**

"Oswin takes the blow on shield and shoulder, staggers a pace, and the clerk calls, 'One touch to Leof.'"

Oswin attacks back and misses.

**Round 2**

Oswin wins initiative, grows bold, and strikes cleanly for **5** damage.

- Formal split: **1 actual**, **4 nonlethal**
- Score: **1 touch**

The bout is now tied **1-1**.

**Round 3**

Leof's player says:

"No more feeling out. I want to take his sword."

The referee resolves a lawful **Disarm** attempt under RC combat maneuvers (RC pp. 103-105). Leof succeeds.

The event awards **2 touches** for a successful disarm.

The score becomes **3-1**, and the bout ends.

**Referee**

"Oswin's sword skips across the trampled ring. The crowd shouts, not in mockery but in delight. The marshal raises his staff. 'Victory to Leof, cleanly won.'"

Oswin is not cast down. He is beaten by score, not ruined.

#### Scene 4: What Happens While the PCs Recover

This is where many supplements go thin. Tournament play should not.

First, the referee handles recovery. Leof has taken marked nonlethal loss, so the RC recovery clock matters (RC p. 267). The referee rolls **2d6 x 10 minutes** and gets **50 minutes** for half recovery.

Second, the opposite semi-final is not central to the table, so it is resolved with the **Off-Stage NPC Bout Procedure**.

Sir Pell and "Sir Morrow" are compared:

- Pell has better reputation, but no mechanical edge.
- "Morrow" has slightly better arms and a more aggressive style.

The off-stage roll favors "Morrow" by **7**, a decisive result.

**Referee**

"The stranger beats Pell hard. There is one sharp crack of shield on helm, a stumble, a shouted warning from the marshal, and then Pell is down on one knee yielding the second touch and the bout."

Because the margin was decisive and the earlier suspicion exists, the referee also notes rising tension without yet calling a scandal roll.

Meanwhile, Brother Cerdic speaks with the herald:

"If that man is false, do not accuse him before the final unless you mean to hold him."

The herald agrees. The master of guards quietly places two watchmen near the purse awning.

That is the second lesson of tournament play: the administrative game continues between bouts.

#### Scene 5: The Final

The final is Leof against "Sir Morrow Blackleaf."

Before blades are crossed, the stranger gives a contemptuous salute and says:

"Let the plowman and the hedge-priest witness how true steel answers market boasting."

Leof's player answers:

"Leof says, 'Then let true names stand with it.' He salutes the reeve and the herald, not the stranger."

The referee asks for opposing social checks.

- "Morrow" fails his Applause Check badly and loses **1 Crowd Standing**
- Leof succeeds and rises to **+2 Crowd Standing**

Because Crowd Standing affects Festival Reaction and Applause rather than attack rolls, combat itself remains pure RC procedure.

**Round 1**

- "Morrow" wins initiative.
- He hits for **4** damage and scores **1 touch**.
- Leof misses.

The stranger leads **1-0**.

**Round 2**

Leof wins initiative and scores a clean hit for **7** damage.

- Formal split: **1 actual**, **6 nonlethal**
- Score: **1 touch**

The bout is tied **1-1**.

At the end of the round, the referee rolls on the **Footman Incident Table** because the fight has gone long enough. The result is **5**: the crowd presses the rail.

**Referee**

"The rope bows inward as merchants, drovers, and apprentices shove for a better look. The marshal curses and beats the air with his wand. No rule changes yet, but the ring feels smaller."

**Round 3**

Anwyn's player says:

"While all eyes are on the ring, I want to get behind the stranger's attendants and look for a second shield or second badge."

The referee allows another ability-based stealthy observation rather than pausing the duel. Anwyn succeeds. She sees one squire cradling a folded surcoat with a different device inside.

In the ring, Leof declares a careful attack rather than a Disarm.

He hits. The damage is enough for **1 touch**.

Leof now leads **2-1**.

**Round 4**

The stranger, suddenly pressed, tries to force the issue and attacks recklessly. He misses.

Leof's player says:

"Now I disarm him. If he is false, I want him bare-handed before everyone."

The Disarm succeeds.

That is worth **2 touches**, but Leof only needed one more to win. The bout ends **4-1** in effect, though the exact excess does not matter once the victory condition is reached.

**Referee**

"The blade leaps from the stranger's hand. It tumbles end over end and lands near the very herald he scorned. The crowd breaks into one shout. The marshal steps between you. The clerk is already calling the victory."

#### Scene 6: Judgment After the Blow

Now the table turns from combat procedure to tournament procedure.

Anwyn presents what she saw. Brother Cerdic supports the herald's caution. Because Leof now has positive Crowd Standing and the stranger has negative standing, the referee gives the ensuing Festival Reaction a favorable shift toward the PCs' testimony.

The master of guards seizes the spare surcoat. Under questioning, one frightened attendant admits that "Sir Morrow Blackleaf" is no knight at all but the landless son of a ruined house, hoping to win purse and patronage under a dead man's colors.

The herald rules **heraldic fraud**.

The purse is not awarded to the impostor, because he lost. More importantly, his false device is seized and the reeve orders him held for judgment overnight.

Leof receives:

- first prize of **100 gp**
- **1 Honor Mark** for winning a local event
- the right to issue one lawful challenge before the next sunset if he wishes

Oswin, who lost honestly and fought above expectation, receives the goodwill of the crowd and is offered training by Sir Pell.

The referee then rolls **Political Fallout** and gets **3**.

**Referee**

"As evening bells sound, the reeve's steward takes Brother Cerdic aside. A messenger from the baron's hall was in the crowd. He asks who this Leof is, who his companions are, and whether they travel north. It seems the fair has bought more than one day's glory."

That roll becomes the session's next adventure hook.

#### What This Session Demonstrates

This one short festival session used all of the following without ever ceasing to feel like ordinary play:

- one host, one purse, and one simple bracket
- Crowd Temper
- Applause Checks and Crowd Standing
- one full bout run round by round
- one off-stage NPC bout
- formal damage and nonlethal recovery
- investigation between bouts
- a tournament foul resolved after the combat rather than during it
- purse, honor, and political consequence as session aftermath

If the referee wants a first story example to imitate, this is the recommended shape: one compact festival, one suspicious rival, one player-entered event, and one consequence that leads beyond the lists.

## Closing Counsel to the Referee

Do not let the tournament harden into arithmetic. The ledger, the lists, the purse, the herald's cry, the mud on the rail, the bad blood between houses, the tired horse, the proud fool who should have yielded one pass sooner: these are all part of the same machine.

If the field runs cleanly, the rules have done their work. If the field breeds challenge, wager, resentment, and glory without collapsing into confusion, the rules have done better still.
